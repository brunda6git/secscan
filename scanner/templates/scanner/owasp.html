OWASP Top 10
The most critical web application security risks, maintained by the Open Worldwide Application Security Project. Items highlighted in green are actively checked by SecScan.
A01Broken Access Control
Users can act outside their intended permissions — viewing or modifying data, or reaching admin functions they shouldn't.
A02Cryptographic Failures
Sensitive data exposed due to weak, missing, or misconfigured encryption in transit or at rest.
✓ Checked — SSL Certificate
A03Injection
Untrusted input interpreted as code or commands (SQL, OS, LDAP), letting attackers manipulate backend systems.
A04Insecure Design
Security flaws baked into the architecture itself — missing threat modeling or weak design patterns.
A05Security Misconfiguration
Missing security headers, default credentials, verbose errors, or unnecessary open ports.
✓ Checked — Headers, Ports, Leakage
A06Vulnerable Components
Using libraries or software versions with known, publicly disclosed vulnerabilities.
✓ Checked — Server Info Leakage
A07Identification & Auth Failures
Weaknesses in login, session management, or credential handling that let attackers impersonate users.
A08Software & Data Integrity Failures
Code or infrastructure that doesn't verify integrity — unsigned updates, insecure CI/CD pipelines.
A09Security Logging & Monitoring Failures
Insufficient logging and alerting means breaches go undetected, delaying response.
A10Server-Side Request Forgery (SSRF)
An attacker tricks a server into making requests to unintended internal or external destinations.

About SecScan

SecScan is an automated scanner built to make the OWASP Top 10 concrete and actionable — not a substitute for a full professional audit.

  • Checks HTTP security headers, SSL/TLS config, HTTPS enforcement, open ports and server leakage
  • Produces a weighted 0–100 risk score with LOW / MEDIUM / HIGH / CRITICAL rating
  • Generates a downloadable PDF report with fixes for every failed check
  • Flags major enterprise platforms separately, since their public score doesn't reflect internal security infrastructure
  • Built with Django, deployed on Render
Reference: OWASP Top 10 (2021 edition) · owasp.org
